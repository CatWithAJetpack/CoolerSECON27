# Pre-Match

Source: GM2 V3.0, sections 3.4.1 and 3.5.

## Field Personnel Checklist

- [ ] Field set up per GM2 Figure 3.2.1
- [ ] Die rolled, pit box determined (see pit-stop.md for the die roll table)
- [ ] AprilTag for the assigned pit box (ID 1, 2, or 3) fastened to the wall by the starting area
- [ ] Three obstacle cars placed in the Appendix E zones on the straightaways, in the inner lane and the outer lane
- [ ] Green start flag secured in the **down** position
- [ ] All field elements within ± 1 in. position tolerance

---

## Technician Checklist

- [ ] Robot placed completely inside the start box
- [ ] Robot within the 12 x 12 x 12 in. starting size (GM1 <R01>)
- [ ] Red tire pre-loaded on the robot
- [ ] All settings selected
- [ ] Robot declared ready to the referee

---

## Rules

- The technician may set and position the robot in any way within the 12 in starting cube. Touching any other part of the field or game elements is a Red Card (GM2 <G08>).
- Do not interact with the field after randomization. Any interaction voids scoring for all tasks affected by randomization: obstacles and the AprilTag (GM2 <GS01>).

---

## AprilTag

- Selected before the race by the die roll.
- Shows the assigned pit box: ID 1, 2, or 3.
- See apriltags.md.
